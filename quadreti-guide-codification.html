Les quatre mots du mur

Avant de commencer : qui est qui.

Quatre mots suffisent pour tout comprendre. Les voici, une fois pour toutes.

Le carreau

La grille murale. Elle accueille 7 × 7 tesselles. Un mur peut compter un ou plusieurs carreaux.

La tesselle

La pièce qui se clipse dans le carreau. C'est le support.

L'étui

Il habille la tesselle et maintient le visuel. C'est lui qui rend le visuel changeable.

Le visuel

Le papier imprimé par vous : photo, couleur, motif. Le code de repérage est imprimé à son dos.

Le principe

Une lettre, un chiffre. Rien d'autre.

La lettre donne la ligne, le chiffre donne la colonne. Suivez la lettre, suivez le chiffre : là où ils se croisent, c'est la place.

Du carreau au mur : la double lecture

Le mur est une grille de carreaux. Chaque carreau, une grille de places.

Reprenez la grille que vous venez d'apprendre : la voici sur le mur, entourée de ses voisins. Le mur se lit exactement de la même façon — la lettre en haut, le chiffre sur le côté. Deux grilles, une seule logique.

De l'app au dos du visuel

Un seul repère, trois endroits.

Le repère affiché dans l'app est imprimé au dos de chaque visuel — généré automatiquement avec votre fiche d'impression. Vous n'écrivez jamais rien.

À vous de jouer

Vrai ou faux ?

Trois questions pour vérifier — et vous verrez que c'est déjà acquis.

Le code B2 · D5 signifie : carreau B2, colonne D, ligne 5.

La partie terracotta du code indique le carreau du mur.

Sur un mur d'un seul carreau, le code se réduit à la place : D5.

Ranger, remonter… et y revenir à chaque occasion

Une composition se range dans son album. Et revient.

Déclipsez, glissez chaque visuel dans sa pochette — la page reprend la grille du carreau, chaque visuel garde sa place. Remonter le mur, c'est lire la page.
