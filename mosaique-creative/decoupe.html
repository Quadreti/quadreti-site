Aide

Insérez des pièces, glissez-les. Activez « Les pièces se découpent entre elles » pour qu'elles se redécoupent entre elles et respectent le joint. Sélectionnez une pièce pour la redimensionner ou courber ses bords.

  • Glisser une pièce = la déplacer (et mordre celles du dessous si la découpe entre pièces est activée).
  • Glisser un espace vide = déplacer la vue.
  • Ctrl/Cmd + molette = zoomer sous le curseur.
  • Poignées : coin = redimensionner, milieu d'un bord = courber.
  • Clic droit = couleur / verrouiller / dupliquer / supprimer.
  • Maj + clic = sélection de groupe. Maj + glisser sur le vide = rectangle de sélection multiple.
  • L = verrouiller/déverrouiller le groupe sélectionné, ou tout s'il n'y en a pas.
  • Ctrl+Z / Ctrl+Maj+Z = annuler / rétablir.
  • Une loupe apparaît pendant l'ajustement d'une poignée ; des guides roses s'affichent en approchant du centre ou d'une autre pièce.
Remplissage ▾

Personnaliser le clic droit

Coche/décoche une action, glisse une poignée pour la réordonner dans son groupe. Couleur et Supprimer restent toujours actifs.
